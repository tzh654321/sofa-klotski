# test/once —— 一次性体检（不参与全量回归）

这里放「**检查已有关卡是否符合要求**」这类测试：它们锁的是某一关的具体内容
（块数、配色、命名、连通块合并、难度记录…）。关卡内容会随设计调整，这些断言写死了就会
每次全量都红一片，所以从 `test/` 挪出来：

- `node test/run-all.js` **不会**跑这个目录（它只扫 `test/*.test.js`，不进子目录）
- 想跑全部：`node test/once/run.js`
- 想跑单个：`node test/once/forest-maze.test.js`

## 什么时候用它
- 改完某一关的**内容**（重画墙、改名字/颜色、调难度），想确认没画错、没漏合并、记录没漂
- 新关第一次入册，想按"这一关的规格"做一次体检
- **不要**把行为回归（引擎规则、页面交互、写盘 API）放进来——那些必须每次跑

| `wall-maze.test.js` | 狼烟四起2-1：社区 LURD 文本关按推箱子记关法导入的结果 |

写这类测试的原则：**能从文件里读的期望值就别写死**。要么读文件做自洽校验（数量取自
`rec.level`，把 `meta` 和现算的 `analyze` 对比），只有"画错了/漏合并了/记录漂了"才红。
