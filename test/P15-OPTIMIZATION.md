# 十五子最短解优化记录

## 本次实现

- 连锁推模式禁止连续同轴动作。因为同一行/列内非空数字的次序保持不变，两步可合并为一步或抵消，最短路径必定横竖交替。单格模式不启用此剪枝。
- 转置表键加入上一动作轴，避免合并后继约束不同的状态。
- 设 a=ceil(H/3)、b=ceil(V/3)：根下界为 max(a+b,2max(a,b)-1,0)；上一动作为水平时为 max(2a,2b-1,0)，为竖直时为 max(2a-1,2b,0)。与模式库取最大值。
- 先用廉价下界过滤候选，再在真实子棋盘上查询模式库，并将结果传给递归复用；原实现排序时误用父棋盘的模式库值。
- 将超阈值过滤放到转置表插入前，减少字符串和 Map 操作。
- 初始阈值包含模式库；完整精确搜索超时返回当前已证明的下界。
- oneBound/rootOnly 局部搜索不再自行宣称全局最优。

## 验证

Node v24.19.0，Windows，本机单次测量，不代表所有机器或随机盘面的平均收益。

独立目标反向 BFS 深度5：727个连锁推盘面、95个单格盘面，每个均以 TT 开/关验证最短长度与合法路径回放。既有测试31项全通过。浅局面因同轴剪枝已消除重复，原有“TT必须严格减少节点”断言调整为“不增加”，保留长度和回放检查。

四张原有模式库 [[1,2,3,4],[5,9,13],[6,7,8,10,14],[11,12,15]]，搜索预算各5秒，构表时间不计入搜索：

|盘面|旧耗时|新耗时|旧/新节点|结果|
|---|---:|---:|---:|---|
|case 2 随机游走|8ms|3ms|1303 / 520|同为18手最短|
|case 3 随机排列|5000ms|5001ms|1416807 / 3058079|均超时，阈值29 / 30|
|case 4 随机排列|5000ms|5001ms|1412507 / 3112797|均超时，阈值31 / 32|
|case 5 随机排列|906ms|208ms|287466 / 146606|同为26手最短|

固定盘面及原始结果见本目录 p15-pdb-benchmark.json。超时盘面的展开更多仅代表同预算内完成更多工作，不代表已求解或总完成时间的加速比。毫秒级测量噪声较大。

## 复现

在工作区执行：

```powershell
node sofa-klotski/test/p15-opt.test.cjs
node sofa-klotski/test/p15-pdb-bench.cjs
node sofa-klotski/test/p15.test.js
```

puzzle15-baseline.cjs 是修改前快照，仅用于基准，不由网页加载。p15-opt.test.cjs 生成固定盘面文件，之后运行模式库基准。axisPrune:false 可关闭交替剪枝与对应下界，但仍保留其他优化。

## 边界

完全随机最短解仍是指数级搜索；此次有实际收益，但不能保证所有盘面秒出。后续仍有更强方向成本模式库、按阈值协调的多 worker 搜索、紧凑且校验完整状态的转置表等方向，不能断言已无优化空间。现有模式库按标准目标构建，本次沿用页面的标准目标/连锁推配置；任意目标与不匹配的外部模式库组合并未扩展支持。未运行浏览器端自动化，验证集中于页面及 worker 共用的求解器模块。
