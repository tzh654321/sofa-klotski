难度分—
难度（模型 v3）= 操作长度 32 + 调度结构 32（每次重建 / 撤退 / 最长铺垫的来回次数） + 选择干扰 16， 再乘一个长度门槛，并计入长程调度 20 分。状态空间与路径总数不计分（局面大只是「看不过来」，不等于「想不明白」）。
专用求解4阶数字华容道
快速解 = 加权 A*；最短解 = IDA*+PDB；分层解 = 分三层逐层摆好。
这一关带「随机打乱」属性：每次载入 / 复位都会重新乱一次，难度分是抽样平均（见关卡文件）。
专用求解织布机
24 个梭子各回各位。这关的局面实在太多，通用枚举跑不完， 这里用加权 A* 逐个权重试出一条**能走通的解**（十几秒到一分钟），不证明最短。

目标怎么设？
一条目标 = 一组落点 + 归位的块。点列表里的目标可以继续加料：＋落点（到任一个都算）、 ＋块 配 全部就位（每块各占一个落点，位置可换）或 任一就位（有一块到位就达成）。 ＋空格 建一条"这几格必须空着"的目标，再点棋盘空格子加入 / 移出。
